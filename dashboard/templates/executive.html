The 3 Agents

Each agent has a focused role, dedicated tools, and produces an explainable step in the brain log.

Agent 1

Context & Signal Agent

Enriches the passenger picture by combining the Snowflake MCP profile with live Iceberg operational signals — flight delays, connection risk, and chat constraints (e.g., must land before 6 PM).

Iceberg fetch_operational_context

Agent 2

Uplift & Strategy Agent

Classifies the passenger archetype (Sure Thing, Persuadable, Sleeping Dog, Choice-Oriented) using uplift history, then recommends the optimal gesture from the action shelf — auto-rebook, hold-and-prompt, lounge access, or concierge handoff.

Iceberg query_uplift_and_actions

Agent 3

Fulfillment & Guardrail Agent

Validates inventory, blocks backfiring actions (e.g., vouchers for Sleeping Dogs), confirms rebooks or holds, and writes the final decision to the Iceberg audit table for executive reporting.

Iceberg query_inventory · log_execution_result
